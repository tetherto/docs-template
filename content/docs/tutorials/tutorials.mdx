# Tutorials

Tutorials are step-by-step guides designed to help you learn by doing. In this section, you will find hands-on walkthroughs that take you from start to finish on a specific task or project using DOCS.

## What to Expect

- Guided, practical exercises
- Explanations of key concepts as you progress
- A focus on learning by building real examples

Tutorials are ideal for beginners or anyone looking to gain a deeper understanding of how to use DOCS in real-world scenarios.

Learn more about the role of tutorials in documentation from the [Diataxis framework](https://diataxis.fr/tutorials/).
