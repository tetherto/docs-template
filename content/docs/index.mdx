# Welcome to DOCS

DOCS is a flexible, white-label documentation platform designed to help you create, manage, and publish high-quality technical documentation. This site is organized to help you quickly find the information you need, whether you're just getting started or looking for advanced guides.

## Main Sections

- **Explanation:** Conceptual context behind the DOCS project — goals, design decisions, and trade-offs.
- **Getting Started:** Step-by-step instructions to help you install and use DOCS, including a quickstart guide.
- **How-tos:** Practical, task-oriented guides for solving specific problems using DOCS, following the [Diataxis](https://diataxis.fr/) framework.
- **References:** Comprehensive, factual reference material for APIs, configuration, and more.
- **Tutorials:** Hands-on, project-based tutorials to help you learn by doing.
